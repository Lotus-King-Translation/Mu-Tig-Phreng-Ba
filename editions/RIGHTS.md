# Source rights

Repository code or documentation licensing does not relicense external source material. Every source retains its own terms.

- **BDRC public-domain facsimiles:** collection rights metadata is preserved beside each volume manifest. Original IIIF response images are archived byte-for-byte; the PDF is a lossless image-only derivative. BDRC is attributed in each image manifest.
- **Gadkar photographs:** © Tibetan Manuscript Project Vienna, photographs 2023; [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/). The historical work's generic public-domain designation does not supersede this explicit photograph licence. W1BL6 and rearranged W1ER156 use the same photographs. Images are unchanged; Lotus King Translation packaged them as a lossless PDF and ZIP. Original licence evidence: `research/bdrc/batch-03-access-and-provenance/W1BL6.json`, `bdo:scanInfo`. Attribution and noncommercial terms apply to downstream image reuse.
- **Wikisource:** preserved page/history attribution and CC BY-SA 4.0 terms are documented in `research/etexts-translations/wikisource/README.md`. Wylie and Tibetan are one Valby/Adzom-derived transcription family.
- **British Library EAP:** catalogue links and source descriptions are recorded. Gangtey manuscript reproduction requires written permission from the monastery; no facsimiles were republished here under an assumed open licence.
- **Commercial translations and unavailable theses:** bibliographic records only. No book text or thesis file was acquired from unofficial sources.

Public accessibility is not a statement of independent witness status or blanket permission for reuse. See the source-specific metadata when collection and image rights differ.
